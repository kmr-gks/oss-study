# Replication Package

This replication package contains the datasets and Python scripts required to reproduce the tables, figures, and statistical test results reported in the paper.

## 1. Environment Setup

This package requires Python 3.

Install the required Python packages by running:

```bash
python3 -m pip install -r requirements.txt
```

All scripts should be executed from the root directory of the replication package.

Example:

```bash
cd replication-package
python3 tableI.py
```

## 2. Datasets

### 2.1 Data Used for Prompt Tuning

Two different datasets, each containing 381 expense records, were used for prompt tuning.

* `data1.csv`
  The first set of 381 expense records used for prompt tuning. It contains manually assigned labels and labels generated by the large language model.

* `data2.csv`
  A second set of 381 expense records used for prompt tuning. This dataset is different from `data1.csv` and contains manually assigned labels and labels generated by the large language model.

### 2.2 Data Used for Expense-Purpose Classification

For the main expense-purpose analysis, 1,784 expense records were classified by the large language model in two separate runs.

* `data3.csv`
  Results from the first LLM classification run.

* `data4.csv`
  Results from the second LLM classification run.

### 2.3 Parquet Files Used for the Analysis

The data extracted from the original database are stored as Parquet files in the `data` directory.

```text
data/
├── collectives.parquet
├── collective_transactions.parquet
├── commit_history.parquet
└── github_issue_pr_items.parquet
```

The `duckdb_util.py` script registers these Parquet files as the following virtual tables in DuckDB:

```text
public.collectives
public.collective_transactions
public.commit_history
public.github_issue_pr_items
```

Therefore, PostgreSQL does not need to be installed, and the original database does not need to be restored.

## 3. Evaluation of the Labeling Results

### 3.1 Inter-Rater Agreement

The following script calculates Cohen's kappa coefficient and the simple agreement rate between the manual classifications performed by two authors in `data2.csv`.

```bash
python3 cohen_kappa_score.py
```

The results are displayed in the standard output.

### 3.2 Accuracy of the LLM Classification

The following script compares the manually assigned ground-truth labels with the LLM-generated labels in `data2.csv`.

It reports the classification accuracy for:

* all records; and
* records for which the LLM confidence score is at least 0.9.

```bash
python3 accuracy_calculation.py
```

The results are displayed in the standard output.

## 9. Notes

* All scripts are intended to be executed from the root directory of the replication package.
* Tables are exported as CSV files, and figures are exported as PDF files.
* Some statistical test results are displayed only in the standard output.
* Scripts that perform currency conversion use `forex-python` to retrieve exchange rates against the US dollar. Therefore, an Internet connection is required when running these scripts.
* Because exchange rates may change over time, monetary results may differ slightly from the values reported in the paper depending on the execution date.
* Minor numerical differences may also occur because of floating-point arithmetic or differences in library versions.
* The appearance of generated PDF files, including fonts, margins, and line breaks, may vary slightly depending on the operating system and Matplotlib version.
